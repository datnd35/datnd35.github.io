## 2) Part 1 — Architecture Thinking (Khóa học hiện tại)

**Mục tiêu:** Hiểu các nguyên lý (Principles) và khái niệm (Concepts) của Software Architecture dành cho các hệ thống lớn.

```text
Large Scale System
        │
        ▼
Architecture Principles
        │
        ▼
Architecture Concepts
        │
        ▼
How Large Systems Work
```

Tập trung vào:

- **Software Architecture Principles** — những nguyên tắc nền tảng khi thiết kế hệ thống lớn.
- **Architecture Concepts** — các khái niệm cốt lõi: scalability, reliability, performance, security...
- **Large Scale Systems** — hiểu cách các hệ thống lớn thực sự hoạt động.

> Phần này thiên về **tư duy kiến trúc (Architecture Thinking)** hơn là lập trình code.

---

## 3) Part 2 — Implementation (Khóa học tiếp theo)

Sau khi nắm vững tư duy kiến trúc, khóa học thứ hai đi vào cách **xây dựng hệ thống thực tế**.

```text
Architecture Design
        │
        ▼
Implementation
        │
        ▼
Technology
        │
        ▼
Configuration
        │
        ▼
Running System
```

Bao gồm:

- Viết code và cấu hình hệ thống.
- Lựa chọn công nghệ phù hợp.
- Triển khai và chạy thử một Large Scale System thực tế.

---

## 4) So sánh Part 1 vs Part 2

| Part 1                | Part 2                |
| --------------------- | --------------------- |
| **What** (Cái gì)     | **How** (Như thế nào) |
| Concept               | Implementation        |
| Principles            | Coding                |
| Architecture Thinking | Hands-on Practice     |
| Hiểu _tại sao_        | Học _làm thế nào_     |

```text
Part 1          Part 2
========        ========
Learn WHY  →   Learn HOW
```
